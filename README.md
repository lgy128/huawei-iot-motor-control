# 基于华为云IoTDA的直流电机云边闭环PID仿真系统
> 自动化控制考研复试工程项目，实现云-边-端三级闭环调速演示

## 一、项目简介
本项目在本地通过Python仿真直流电机对象与PID控制器，依托WSL2+Docker构建边缘运行环境；通过MQTT协议对接华为云IoTDA物联网平台，实现电机转速实时上云、云端远程下发目标转速指令，完成完整的云边闭环控制流程。

## 二、系统架构

【云端层：华为云 IoTDA 平台】
↑ 上报转速属性    ↓ 下发调速命令
MQTT TLS 加密通信
【边缘层：WSL Ubuntu + Python 运行环境】
↑ 采集转速        ↓ 输出控制量
【被控对象：直流电机一阶惯性环节仿真模型】
## 三、技术栈与环境
- 本地环境：Windows 11 + Docker Desktop + WSL2 Ubuntu 24.04
- 开发语言：Python 3.12
- 核心依赖：paho-mqtt（MQTT通信）、numpy（数值计算）、matplotlib（曲线绘图）
- 云平台：华为云IoT设备接入服务（IoTDA）标准版免费实例

## 四、核心功能
1.  直流电机一阶惯性+延迟环节数学仿真
2.  位置式PID闭环控制算法，支持参数在线调整
3.  MQTT双向通信：设备属性上报、云端命令下发
4.  转速响应曲线实时绘制与结果导出
5.  云端远程修改目标转速，动态调整控制效果
